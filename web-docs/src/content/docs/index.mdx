## Not built yet

Lumit is in public beta, and these pages say so where it matters rather than
describing features that do not exist:

- [Audio](/use/audio/) — the largest gap. No audio layers, waveforms, or beat markers.
- [Expressions](/use/expressions/) — specified, partly built, not usable.
- [Cameras and 3D](/use/camera/) — cameras work; light layers do not.
- [Retiming](/use/retime/) — flow interpolation is unfinished; nearest and blend work.
- [Effects](/use/effects/) — 33 built-in effects; plugin hosting is not built.
