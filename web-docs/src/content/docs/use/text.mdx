A **Text layer** holds editable styled text.

<Shot file="text-layer.png" caption="A text layer being edited in the Viewer." />

## Add text

1. Pick the Type tool.
2. Click in the Viewer.
3. Type.

## Style it

Set the font, size, letter-spacing, fill, and stroke. Every value can be animated. See
[Keyframes](/use/keyframes/).

Because a text layer is a layer, it also takes [effects](/use/effects/),
[masks](/use/masks/), and a [transform](/use/transform/) like any other.

## Current limit

A text layer holds **one run** in this version. One set of styling applies to the whole
layer. Mixed styling within a single layer is not built.

Use one layer per style until it lands.
