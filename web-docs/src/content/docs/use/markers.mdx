A **marker** is a labelled point on a composition or a layer. Comp markers draw as small
flags on the Timeline ruler; layer markers draw on the layer's own bar and travel with it.

<Shot file="markers-ruler.png" caption="Comp markers and beat markers on the Timeline ruler." />

One marker per frame: adding a marker where one already sits replaces it, and so does
dragging one on top of another.

## Add, move, edit

| Action | How |
| --- | --- |
| Add at the playhead | **Composition ▸ Add marker at playhead**, or `*` (`Shift+8`), or `Shift+M` |
| Move | Drag the flag along the ruler |
| Rename or delete | Right-click the flag: *Edit marker…* or *Delete marker* |

## Numbered markers

1. Press `Shift+0`–`Shift+9` to set that numbered marker at the playhead. Pressing the
   same chord again moves it.
2. Press the bare digit `0`–`9` to jump to that marker. Nothing happens until it has
   been set.

## Beat markers

**Beat markers** are markers generated by audio onset detection. On a comp with audio:

- **Composition ▸ Detect beats** analyses the comp's audio and writes beat markers.
- **Composition ▸ Clear beat markers** removes only the generated ones.

Detection runs in the background; a comp with no audio does nothing.

:::note[Not built yet]
Sensitivity tuning and tapping beats by hand during playback are planned. Known wart:
dragging or renaming any marker currently turns beat markers into ordinary markers, so
*Clear beat markers* stops finding them.
:::
