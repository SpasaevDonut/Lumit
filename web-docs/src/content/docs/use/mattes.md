A **matte** uses another layer to gate this layer. Choose the matte layer from a
dropdown on the layer that should be gated.

Lumit says *matte*. After Effects calls the same idea a track matte.

## Alpha or luma

| Kind | Gates by |
| --- | --- |
| **Alpha matte** | The matte layer's transparency. |
| **Luma matte** | The matte layer's brightness. |

Both can be inverted.

## Any layer, and one to many

Any layer can be chosen as a matte. It does not have to sit directly above the layer it
gates.

One matte layer can serve many layers at once.

## Matte or mask?

- Use a [mask](/use/masks/) when you can draw the shape.
- Use a matte when the shape comes from an image, some text, or a render.
