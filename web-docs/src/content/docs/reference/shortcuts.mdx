Every shortcut in Lumit is rebindable. `Ctrl` below means `Cmd` on macOS.

<Shot file="keymap.png" caption="The keymap editor in Settings." />

## Finding a shortcut

The menus show the current binding beside each command, and they take it from the
keymap rather than carrying a chord of their own. So the menu is always right, even
after you rebind something.

## The keymap editor

**Settings → Keymap** lists every binding, grouped by the context it is live in
(Anywhere, Tools, Timeline, Viewer, and so on). Above the table: a search box, two
presets — Lumit's default and an **After Effects** preset for muscle memory — and
**Import** / **Export** for a shareable keymap file.

1. Click a chord cell.
2. Press the keys you want. `Escape` leaves it, `Backspace` clears it.
3. **Reset** puts the shipped chord back.

A chord another action already holds is taken rather than refused, so you can swap two
actions' keys.

## Most-used defaults

| Keys | Does |
| --- | --- |
| `Space` | Play / pause |
| `J` / `K` / `L` | Shuttle reverse / pause / forward |
| `Page Down` / `Page Up`, arrows | Next / previous frame |
| `Home` / `End` | Comp start / end |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / redo |
| `Ctrl+S` | Save |
| `V` `H` `Z` `W` `Y` `C` `Q` `G` | Selection, Hand, Zoom, Rotation, Anchor, Razor, Shape, Pen — see [the toolbar](/panels/toolbar/) |
| `P` `S` `R` `T` `A` | Reveal position / scale / rotation / opacity / anchor |
| `B` / `N` | Set work area start / end |
| `Shift+0…9` | Set numbered marker at the playhead |
| `0…9` | Go to that numbered marker |
| `Shift+M` | Add a marker |
| `Ctrl+D` | Duplicate the selection |
| `Ctrl+Shift+C` | Precompose |
| `Ctrl+Alt+T` | Give the selected layer a Retime |
| `Ctrl+M` | Add the comp to the export queue |
| `Ctrl+Shift+P` | Command palette |

## Not wired yet

Some bindings in the Tools, Project, Panels and Effects contexts have no command
behind them yet: the chord is real, and pressing it does nothing. They stay listed so
the keymap teaches the intended shape of the application.
