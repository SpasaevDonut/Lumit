This panel lists every effect available, grouped by category, plus saved presets.

| Group | What it holds |
| --- | --- |
| **Built-in** | The 33 effects that ship with Lumit. |
| **Presets** | Configured effects, shipped and your own. |
| **Favourites** | Effects you have starred. Not built yet. |
| **OFX** | Third-party OFX plugins. Not built yet. |
| **LFX** | Lumit's own plugin format. Not built yet. |


<Shot file="effects-presets.png" caption="The Effects & Presets panel." />

## Apply one

Drag an effect onto a layer, or select layers and double-click the effect.

The **Effect** menu does the same thing and applies to every selected layer at once.
