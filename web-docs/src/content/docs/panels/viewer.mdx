The Viewer shows the composition at the playhead. Its bar carries the controls that
change how you see it, never what you export.


<Shot file="viewer.png" caption="The Viewer, with a layer selected and its transform gizmo showing." />

## The Viewer bar

<Shot file="viewer-bar.png" caption="The Viewer bar." />

| Control | Does |
| --- | --- |
| **Magnification** | Zoom level. Zooming is anchored on the pointer. |
| **Preview resolution** | Full, half, third, quarter, or auto. Real downsampling. |
| **Channel view** | Show RGB, one channel, or alpha. |
| **Transparency grid** | Draw a chequerboard instead of black behind alpha. |
| **Background colour** | The colour behind the composition. |
| **Guides menu** | Guides, rulers, safe areas, and the grid. |
| **Wireframe/overlay menu** | Which overlays draw over the picture. |
| **Region of interest** | Render only a box you drag. Useful on heavy shots. |
| **Current time** | The playhead's time. Type in it to jump. |
| **Colour management indicator** | The colour space being shown. |
| **Degradation indicator** | Lights when the engine has lowered quality to keep up. |

Preview resolution and degradation affect preview only. See
[Preview and playback](/use/preview/).

## On the picture

Select a layer and the Viewer draws its wireframe and a transform gizmo. Drag the
handles to move, scale, and rotate. See [Transforming layers](/use/transform/).

Animated position draws a motion path you can shape directly.
