Scopes read the frame the Viewer is showing. Use them when a monitor cannot be trusted.

| Scope | Shows |
| --- | --- |
| **Waveform** | Brightness against horizontal position. Use it to set exposure and check legal levels. |
| **Vectorscope** | Hue and saturation on a colour wheel. Use it to judge a grade and find casts. |
| **Histogram** | How many pixels sit at each level. |

Scopes follow the Viewer, so they update as you scrub.
